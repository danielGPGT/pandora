# Utility Scripts

This directory contains utility scripts for development, deployment, and maintenance.

## Available Scripts

### Database
- `db/migrate.sh` - Run database migrations
- `db/seed.sh` - Seed database with initial data
- `db/reset.sh` - Reset database (development only)

### Development
- `dev/check-types.sh` - Type check without building
- `dev/lint-fix.sh` - Auto-fix linting issues

### Deployment
- `deploy/validate-env.sh` - Validate environment variables
- `deploy/build-check.sh` - Verify build succeeds

## Running Scripts

Most scripts are designed for Unix-like systems (Linux/macOS). For Windows, use Git Bash or PowerShell equivalents.
